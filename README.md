# Field · Proyecto Macarena

Propuesta comercial y material de soporte de **Field** — un producto de **Trii**.

> **Field:** el avance de obra deja de declararse y pasa a verificarse. Field lee lo que ya circula en la obra (WhatsApp, fotos, notas de voz, dron y BIM) y lo verifica contra el modelo 3D y la programación, para que el comité empiece con todos leídos y el atraso se corrija el día que aparece.
